# Mockups

Interactive mockups made on a claude.ai Design canvas. Each `.dc.html` file is one artboard. `canvas.json` is the canvas layout. The files need the canvas runtime (`support.js`) to render. All names and numbers are made up.

| Artboard | File | What it shows |
|---|---|---|
| A · Attached sidebar | Main.dc.html | The first full window: session cards, tabs, the Claude Code pane, the New session and Prompts panels |
| B · Command bar | CommandBar.dc.html | Search sessions, saved prompts and actions; send one prompt to several sessions |
| C · Parts | Parts.dc.html | Card states, toasts, slash commands, status lines and the band above the prompt |
| D · Command center | Command.dc.html | Needs you (only design decisions and destructive changes), what runs, what was handled for you |
| F · Closed sessions | Restore.dc.html | Reopen closed, crashed or ended sessions; after a restart: "Pick up where you left off" |
| G · Chat as cards | Cards.dc.html | One turn as plain text, as terminal cards, and as a Graphite panel |
| H · Calm session view | Calm.dc.html | A very sparse version (too sparse) |
| I · Hybrid | Hybrid.dc.html | **The chosen direction for the session view**: a calm center, one clear action, and a Session rail where every item opens |
| J · Start on another machine | Machines.dc.html | Pick one or more machines, sync git, split the work, send basic tasks to Claude cloud |
| K · Agents and projects | Agents.dc.html | Global roles with models and subagents; task types per project; projects per machine |

There is no artboard E. A phone view was dropped: herdr stays a desktop app.
